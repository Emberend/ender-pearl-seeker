# v0.11.0 — 体验、性能与工程化

这一版把之前欠的债集中补了一轮：设置入口、聊天播报、双语、状态持久化、HUD 分配优化，以及算法层单元测试。

## 新功能

- **ModMenu 入口（可选）**：装了 ModMenu 后可以在模组列表里直接点「设置」。没装不影响任何功能。
- **聊天播报坐标**：锁定目标时把坐标、距离、置信度发到聊天栏，方便回看和分享。设置界面和配置项 `notifyChat` 均可关闭。
- **未完成定位持久化**：还没算出结果的方位射线会写入 `config/eyelocator_state.json`，退出游戏重进可以接着投。换维度会丢弃上一个维度的残留。
- **中英双语**：HUD、管理界面、命令提示全部改走语言文件，跟随游戏语言切换；内置通道名（末地要塞、墓穴之眼、灾变地牢等）也改为翻译键，英文环境下不再混入中文。
- **归档路标名称**：Forge 版未命名条目会显示所属通道名，与 Fabric 版对齐。

## 改进

- **HUD 性能**：面板文本、颜色解析、距离文字、归档名称都做了缓存；静止时每帧不再重新拼接字符串，也不再反复解析十六进制颜色。
- **设置界面**：改为两列布局，新增「聊天播报坐标」「显示标签」「自动识别道具」等开关，小屏（320×240）下也能放下。
- **命令与提示**：所有反馈都走翻译键；通道列表、状态输出格式更统一。
- **状态文件**：损坏或格式不对时只打日志，不会影响游戏启动。

## 修复

- **归档去重范围不一致**：「去重」原先只按当前激活通道过滤，且只判断比较双方中的一条，导致结果取决于最后用了哪个道具，极端情况下还会把别的通道的条目吞掉。现在统一为「同维度 + 同通道 + 距离小于阈值」才合并，并扫描全部通道；跨通道（末地要塞 vs 灾变地牢）即使坐标重合也各留一条。合并规则抽到共享层并补了单元测试。
- **构建产物里的 `fabric.mod.json` 曾是非合法 JSON**：`processResources` 的模板展开会把描述里的 `\n` 变成真实换行，导致描述字符串包含未转义控制字符。现在描述改为单行，产物可被严格 JSON 解析。
- **Forge 归档页置信度**：`Math.round(double)` 返回 `long`，原先直接赋给 `int` 在 Java 17 下编译失败，已修正。

## 工程

- **JUnit 5 单元测试**：新增 `src/test/java`，覆盖 `StrongholdLocator`（求交/投票/离群/近平行/反向交点）、`NextThrowAdvisor`（首次建议/原地投掷/矛盾补投）、`LocatorState`（读写/维度校验/空文件）。Fabric 与 Forge 的 `build` 都会执行，CI 同步生效。
- **构建脚本**：`build-all.sh` 与 CI 逐版本传入 `modmenu_version`。
- **文档**：新增 `docs/modrinth.md`（上架描述），README 更新功能、数据文件、测试与限制说明。

## 升级提示

- 配置项只新增 `notifyChat`（默认 `true`），旧配置可直接使用。
- 未完成定位的状态文件是新增的；旧版本没有这个文件，升级后从空状态开始。
- 这只是个人项目：渲染与各版本兼容性仍未实机验证，Forge 版依然没有进游戏跑过，单元测试只覆盖纯算法层。
